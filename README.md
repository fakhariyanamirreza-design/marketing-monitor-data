# Marketing Intelligence Monitor — رسمیو

یک سیستم نظارت بر اخبار و شبکه‌های اجتماعی (News & Social Media Monitoring) برای تیم مارکتینگ رسمیو.
هر چند ساعت اخبار اقتصادی/صنعتی ایران و اکوسیستم کسب‌وکار را از منابع رایگان فارسی جمع می‌کند،
هر خبر را بر اساس ارتباطش با رسمیو امتیازدهی می‌کند، گزارش را به گروه تلگرام می‌فرستد و
داده‌ها را در این ریپوی خصوصی ذخیره و push می‌کند.

> چرا فارسی؟ برند رسمیو و رقیبش لینکا اولویت دارند؛ اخبار فارسی و محتوای «اطراف خودمان» (اقتصاد و
> اکوسیستم کسب‌وکار ایران) مهم‌ترین خروجی این سیستم است. اخبار انگلیسی رقبای بین‌المللی حذف شده‌اند.

## نحوه کار

- اجرا با **GitHub Actions** هر ۳ ساعت (بدون نیاز به سرور/کارت اعتباری) + امکان اجرای دستی (`workflow_dispatch`).
- **گزارش‌های روزانه و هفتگی** به صورت جداگانه زمان‌بندی شده‌اند (هر روز ۰۸:۰۰ و هفته‌ای یک‌بار پنجشنبه ۰۸:۰۰ به وقت تهران).
- منابع (همه بدون لاگین و بدون API):
  - **Google News RSS** (`lang=en, geo=IR` با کوئری‌های دوزبانه فارسی/انگلیسی برای پوشش خبر ایران)
  - **صفحات عمومی تلگرام** (`t.me/s/...`) — کانال‌های اقتصادی فارسی
  - **RSS خبرگزاری‌های معروف ایران** — ایرنا، ایسنا، مهر، تسنیم (اقتصادی)، خبرآنلاین، انتخاب، دنیای اقتصاد
- هر خبر:
  - در **دسته‌ها** دسته‌بندی می‌شود (رسمیو, رقبا, Product & AI, ترند مهم بازار, Business Data, اکوسیستم کسب‌وکار ایران, بازار و اقتصاد ایران)
  - امتیاز **Relevance Score 0–100** می‌گیرد
  - **Priority** می‌گیرد: بحرانی ≥75 / بالا ≥55 / متوسط ≥30 / کم‌اهمیت
  - **نوع** می‌گیرد: خبر مستقیم رسمیو / خبر رقیب / ترند مهم بازار / عمومی
  - **دلیل کوتاه** برای امتیاز، همراه با کلیدواژه‌های matched دارد
  - محتوای فارسی **بوست +۸ امتیاز** می‌گیرد (`_is_persian`)
- پیام تلگرام **تمیز و خلاصه** است: اول هر بلوک نام دسته، سپس هر خبر یک خط با الگوی
  `🔸 {سورس} - {تایتل لینک‌شده}` (سورس = تلگرام/گوگل نیوز/ایرنا/ایسنا/مهر/تسنیم/خبرآنلاین/انتخاب/دنیای اقتصاد).
  بین هر خبر یک **خط خالی** می‌آید. امتیاز، اولویت و دلیلِ مچ در پیام نمایش داده **نمی‌شود** تا جا برای
  خبرهای بیشتر باز شود (`max_items_per_report` همان سقف است). تایتل‌ها از ایموجی/هشتگ/آیدی کانال/لینک
  و `<![CDATA[ ]]` پاک‌سازی می‌شوند.
- داده کامل Markdown + JSONL در `data/` ذخیره و push می‌شود (امتیاز/دسته/دلیل در فایل‌ها باقی می‌ماند).
- **گزارش روزانه** (`--daily-report`): خلاصه ۲۴ ساعت گذشته — مجموع/اولویت، تفکیک دسته و منبع، منشن رسمیو، ۵ خبر برتر.
- **گزارش هفتگی** (`--weekly-report`): تحلیل ۷ روز — سهم صدا (Share of Voice) هر دسته، منشن رسمیو/رقیب لینکا، هشدارهای شکایت مشتریان، موضوعات داغ هفته (فقط کلیدواژه‌های فارسی).
- **dedup پایدار**: `data/seen.json` (tracked در git) آیدی آخرین ۳۰۰۰ خبر دیده‌شده را نگه می‌دارد تا
  بین رن‌های Actions تکراری ارسال نشود.

> نکته: سهم صدا و اعداد گزارش‌ها از `data/*.jsonl` محاسبه می‌شوند؛ چون فایل‌ها انباشتی (append) هستند،
> چند روزِ اول ممکن است داده‌های قدیمی انگلیسی (پیش از فارسی‌سازی کوئری‌ها) را هم شامل شوند. به مرور خودکار پالایش می‌شود.

## فایل‌ها

| فایل | توضیح |
|---|---|
| `monitor.py` | موتور: جمع‌آوری منابع، امتیازدهی، گزارش تلگرام، ذخیره‌سازی |
| `config.json` | منابع (تلگرام/گوگل‌نیوز/RSS خبرگزاری) و تنظیمات تلگرام و git |
| `rules.json` | **کاملاً قابل تنظیم**: دسته‌ها، وزن‌ها، کلیدواژه‌ها، `cap`، ضرایب |
| `.github/workflows/monitor.yml` | زمان‌بندی هر ۳ ساعت + push |
| `.github/workflows/daily-report.yml` | گزارش روزانه هر روز ۰۸:۰۰ تهران |
| `.github/workflows/weekly-report.yml` | گزارش هفتگی پنجشنبه‌ها ۰۸:۰۰ تهران |
| `data/` | خروجی‌ها (Markdown روزانه، JSONL کامل، `seen.json` برای dedup) |
| `tools/find_chat_id.py` | یافتن شناسه گروه تلگرام |

فیدهایی که گواهی SSL سالم ندارند (فارس، ایلنا، خبرصدای و…) به دلیل امنیت اضافه نمی‌شوند.

## تنظیم وزن‌ها و کلیدواژه‌ها

وزن‌ها و کلیدواژه‌ها در `rules.json` هستند و بدون دست زدن به `monitor.py` قابل تغییرند:

| پارامتر | محل | توضیح |
|---|---|---|
| وزن دسته | `categories[].weight` | وزن ۰ تا ۱ در امتیازدهی |
| سقف امتیاز | `categories[].cap` | مانع بحرانی شدن غیررسمیوها |
| وزن کلیدواژه | `categories[].keywords[].weight` | شدت هر کلیدواژه |
| کوئری‌های جستجوی گوگل | `categories[].search` | عبارات ارسالی به Google News (دوزبانه) |
| divisor/title/bonus | `scoring.*` | ضرایب فرمول Relevance |
| آستانه‌ها | `priorities.*` | مرزهای Priority |
| حداقل امتیاز | `scoring.min_score` | فیلتر نویز |
| حداکثر آیتم گزارش | `scoring.max_items_per_report` | سقف آیتم در یک پیام تلگرام |

## Secrets (تنظیمات GitHub → Actions secrets)

- `TELEGRAM_BOT_TOKEN` — توکن بات تلگرام
- `TELEGRAM_CHAT_ID` — شناسه گروه (مثلاً `-1004486302229`)

> امنیت: هیچ سکرتی در ریپو ذخیره نمی‌شود؛ همه از Secrets به محیط کاری Actions می‌آیند.
> ایتا/تلگرام/RSS همگی از صفحات عمومی بدون لاگین خوانده می‌شوند (بدون اکانت، بدون session).

## اجرای دستی

```
python monitor.py --once                  # یک چرخه کامل (جمع‌آوری + امتیازدهی + ذخیره)
python monitor.py --once --send-report    # و ارسال به تلگرام اگر توکن تعریف شده باشد
python monitor.py --daily-report          # گزارش روزانه (۲۴ ساعت گذشته) — اگر توکن باشد ارسال می‌شود وگرنه چاپ می‌شود
python monitor.py --weekly-report         # گزارش هفتگی (۷ روز گذشته) — همین رفتار
```

اگر локال توکن/چت‌آیدی تعریف نشده باشد، متن گزارش در کنسول چاپ می‌شود؛ در GitHub Actions (جایی که
Secrets موجود است) به تلگرام ارسال می‌شود.

یافتن chat_id گروه: بات را به گروه اضافه کنید، یک پیام بفرستید، سپس
`python tools/find_chat_id.py` را با `TELEGRAM_BOT_TOKEN=<token>` اجرا کنید.
